## Lab 1 — Лінійні моделі

Ноутбук: [`lab-1/linear_models_lab.ipynb`](./lab-1/linear_models_lab.ipynb)

Короткий зміст:
- Базові вправи NumPy, pandas, PyTorch (генерація масивів, індексація, статистики, reshape, автоград, ручний градієнтний спуск).
- Візуалізація (Matplotlib): графіки функцій, scatter-plots, криві навчання.
- Лінійна регресія з нуля: `torch.nn.Linear` + SGD + MSELoss, train/val/test спліт (70/15/15).
- Власний сценарій: **години сну -> самооцінка продуктивності** (лінійна залежність з $w=1.1$, $b=-2.0$, шум $\mathcal{N}(0, 0.8)$), з обґрунтуванням вибору параметрів у самому ноутбуці.
- Збереження датасету (`dataset.csv`) і натренованої моделі (`model.pt`) на Google Drive.
- Інтерактивний Gradio-віджет для прогнозу продуктивності за кількістю годин сну.
