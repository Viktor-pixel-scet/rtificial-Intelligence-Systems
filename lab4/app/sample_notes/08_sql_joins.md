# SQL: обʼєднання таблиць

| Тип обʼєднання | Що повертає |
|---|---|
| INNER JOIN | лише рядки, що мають пару в обох таблицях |
| LEFT JOIN | усі рядки лівої таблиці; якщо пари немає, права частина містить NULL |
| FULL JOIN | усі рядки обох таблиць |
| CROSS JOIN | усі можливі пари рядків (декартів добуток) |

Приклад запиту, який виводить студентів разом із назвами їхніх груп:

```sql
SELECT s.name, g.title
FROM students s
LEFT JOIN groups g ON g.id = s.group_id;
```

Якщо студент не належить жодній групі, LEFT JOIN усе одно поверне його, а стовпець `title` буде NULL. З INNER JOIN такого студента в результаті не було б.

Умову обʼєднання пишуть у ON, а умову фільтрації — у WHERE. Для LEFT JOIN різниця важлива: умова в WHERE, що перевіряє праву таблицю, відкидає рядки з NULL і фактично перетворює запит на INNER JOIN.
