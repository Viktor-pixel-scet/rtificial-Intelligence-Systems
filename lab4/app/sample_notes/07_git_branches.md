# Git: гілки та злиття

Гілка в Git — це рухомий покажчик на коміт. Створення гілки майже миттєве, бо Git не копіює файли, а лише записує новий покажчик. Поточну гілку визначає спеціальний покажчик HEAD.

## Злиття

Команда git merge обʼєднує зміни іншої гілки з поточною. Якщо поточна гілка не мала нових комітів, Git виконує fast-forward: просто пересуває покажчик уперед. Якщо обидві гілки розійшлися, Git створює окремий коміт злиття з двома батьками. Конфлікт виникає, коли обидві гілки змінили той самий рядок файлу; такі місця Git позначає маркерами <<<<<<<, ======= і >>>>>>>, і розвʼязати їх потрібно вручну.

## Rebase

Команда git rebase переносить коміти гілки на нову базу й переписує їхню історію, створюючи нові коміти з іншими хешами. Через це не слід робити rebase гілок, якими вже користуються інші люди.
